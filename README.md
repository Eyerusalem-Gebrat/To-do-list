# To-do-list
A simple and interactive to do list web application built using HTML, CSS, and JavaScript, with JSON Server as a mock backend. The project supports task management features such as adding, searching, sorting, and toggling dark mode.
The features:
Add new tasks
Delete tasks
Sort tasks
Dark Mode / Light Mode 
Persistent data using JSON Server
Clean and responsive UI
The technologies used:
HTML5 for structure
CSS3 for styling and dark mode
JavaScript for functionality and DOM Application
JSON Server for mock REST API
Git and GitHub for version control and collaboration
This project was developed collaboratively using GitHub:
Team members pushed and pulled changes using Git
Updates were emerged using git pull
Each feature was tested after integration
